## Choose your pathway

Each pathway needs a Simli API key, from your [Simli dashboard](https://app.simli.com). This is everything else you bring yourself:

| Pathway | Runs | What you bring |
| --- | --- | --- |
| [LiveKit Agents](/api-reference/livekit) | A Python agent in your LiveKit room | Your own LiveKit server, reachable from the internet: LiveKit Cloud, or self-hosted with a public address (not `localhost`). A key for your model provider: OpenAI for the starter. |
| [Pipecat](/api-reference/pipecat) | A Python agent on your machine | An OpenAI API key. No other accounts. |
| [JavaScript SDK](/api-reference/javascript) | In the browser | A backend route that creates session tokens, so your API key never goes in the browser. |
| [Python SDK](/api-reference/python) | In your Python program | Nothing else. |
| [Raw WebRTC](/api-reference/simli-webrtc) | In your own client | Your own WebRTC client. |
