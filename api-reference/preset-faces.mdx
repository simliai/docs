These are the presets in the [Simli dashboard](https://app.simli.com/create/from-existing), in the same order. They are all [Trinity-2](/api-reference/trinity-2) faces, so they support framing, camera controls and backgrounds. If you want a custom face, create one here -> [app.simli.com](https://app.simli.com)
