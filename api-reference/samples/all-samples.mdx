#### LiveKit Agents

<Card title="create-simli-app-livekit-agents" icon="github" href="https://github.com/simliai/create-simli-app-livekit-agents">
	A LiveKit Agents voice agent on OpenAI's Realtime API, with a Simli Trinity-2 avatar and a web page to talk to it. See the [LiveKit guide](/api-reference/livekit).
</Card>

#### Pipecat

<Card title="create-simli-app-pipecat" icon="github" href="https://github.com/simliai/create-simli-app-pipecat">
	A Pipecat voice agent on OpenAI's Realtime API, with a Simli Trinity-2 avatar and a web page to talk to it. See the [Pipecat guide](/api-reference/pipecat).
</Card>

#### OpenAI Realtime

<Card title="create-simli-app-openai" icon="github" href="https://github.com/simliai/create-simli-app-openai">
	A Next.js app that talks to OpenAI's Realtime API over WebRTC and speaks the answers through a Simli avatar, using the Simli JavaScript SDK. The API keys stay on the server. See [OpenAI Realtime](/api-reference/samples/openai).
</Card>

#### ElevenLabs Agents

<Card title="create-simli-app-elevenlabs" icon="github" href="https://github.com/simliai/create-simli-app-elevenlabs">
	A Next.js app that gives an ElevenLabs agent a Simli avatar, using the Simli JavaScript SDK. The API keys stay on the server. See [ElevenLabs](/api-reference/samples/elevenlabs).
</Card>

#### Deepgram + OpenAI + ElevenLabs

<Card title="create-simli-app" icon="github" href="https://github.com/simliai/create-simli-app">
	A Next.js app with its own server that chains Deepgram (speech-to-text), OpenAI (LLM) and ElevenLabs (text-to-speech), and shows the result with the Simli JavaScript SDK. All provider keys stay on the server.
</Card>

<Note>Every starter keeps your API keys on the server. In production, the routes that start a session return `403` until you put them behind your own sign-in, since anyone who can call them uses your Simli minutes and provider credit. Each README's "Before you deploy" section says what to set up. Each starter also includes the [Simli agent skill](https://github.com/simliai/skills) for coding agents.</Note>
